# CodeAlpha-FAQ-Chatbot
CodeAlpha FAQ Chatbot 🤖

A simple interactive FAQ chatbot developed using Python as part of my CodeAlpha internship project.

Features

- Answers frequently asked questions about CodeAlpha and Python.
- Uses text similarity matching to identify user questions.
- Provides interactive responses through the command line.
- Supports exit commands such as "bye", "exit", and "quit".

Technologies Used

- Python
- Regular Expressions ("re")
- difflib ("SequenceMatcher")

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open Command Prompt in the project folder.
4. Run the following command:

py chatbot.py

Project Structure

- "chatbot.py" — Main chatbot program.
- "README.md" — Project documentation.

Learning Outcome

This project helped me practice Python programming, string processing, and basic text similarity matching.
